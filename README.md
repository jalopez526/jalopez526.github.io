# jalopez.com

Personal portfolio of Jeremy López. Plain HTML, CSS and JavaScript — no build step.

- `index.html` — page content
- `assets/css/styles.css` — styles (design tokens at the top)
- `assets/js/main.js` — interactions
- `assets/Jeremy-Lopez-Resume.pdf` — downloadable résumé

Preview locally: `python -m http.server` then open http://localhost:8000
